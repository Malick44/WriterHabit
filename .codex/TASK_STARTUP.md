# Task Startup Checklist

Before every implementation, review, debugging, documentation, or planning task in this repository, read these files first:

1. `AGENTS.md`
2. `docs/00_CONTEXT_BRIEF.md`
3. `prompts/01_master_agent_rules.md`
4. `.codex/EXECUTION_STATE.md`

Then read the specific implementation prompt, screen prompt, skill, or source files required by the task.

Keep this checklist non-secret. Do not add environment values, Supabase service-role keys, tokens, or local credentials here.
