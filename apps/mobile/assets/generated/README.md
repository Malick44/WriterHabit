# Generated Assets

Production-candidate generated assets for the WriteWise mobile app belong here.

Current status: no generated app assets have been produced yet.

## Directory Map

- `onboarding/`: onboarding illustrations and visual moments.
- `empty-states/`: empty, offline, and recovery state illustrations.
- `badges/`: badge and reward artwork.
- `canvas-templates/`: handwriting/canvas template thumbnails.
- `paywall/`: subscription and upgrade visuals.
- `store/`: App Store / Play Store screenshot support assets.

## Manifest

Add one entry per generated asset:

```txt
filename:
  path:
  purpose:
  target screen:
  dimensions:
  format:
  generated by:
  reviewed:
  notes:
```

Rules:

- Use lowercase kebab-case filenames.
- Do not place source code in this folder.
- Avoid text inside images unless explicitly required.
- Keep this manifest aligned with `docs/assets/ASSET_GENERATION_PLAN.md`.
