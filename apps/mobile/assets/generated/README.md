# Generated Assets

Production-candidate generated assets and design-support screenshots for the WriteWise mobile app belong here.

Current status: generated onboarding, empty-state, badge, auth illustration, and auth screenshot concept assets exist.

## Directory Map

- `onboarding/`: onboarding illustrations and visual moments.
- `empty-states/`: empty, offline, and recovery state illustrations.
- `badges/`: badge and reward artwork.
- `canvas-templates/`: handwriting/canvas template thumbnails.
- `paywall/`: subscription and upgrade visuals.
- `store/`: App Store / Play Store screenshot support assets.
- `auth/`: auth screen illustrations used by production UI.
- `auth-screenshots/futuristic/`: futuristic auth-flow screenshot design concepts.
