# WriterHabit Child Home Assets

Source: `/Users/malick/Downloads/writerhabit_image_assets_for_codex.zip`.

These PNGs are user-provided dashboard assets for the child-friendly Student Home experience. They were resized from the original 1254x1254 files to 512x512 for mobile UI use. Their generated checkerboard-style edge backgrounds were converted to alpha transparency so they render cleanly on native cards.

## Usage

- `01_maya_avatar.png`: Student Home greeting avatar.
- `02_writing_puppy.png`: Today plan writing illustration.
- `03_cloud_rainbow.png`: Writing coach icon.
- `04_notebook_pencil.png`: Practice stat icon.
- `05_gold_badge_medal.png`: Feedback reward chip.
- `06_stacked_books.png`: Grade 3 Writing Adventure card.
- `07_star_points_badge_128.png`: Weekly writing stat icon.
- `08_streak_flame_icon.png`: Streak stat icon.

Keep these assets local-only and bundled. Do not convert them to remote URLs.
