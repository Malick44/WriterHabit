# Writing Confidence Screen

## Target user
Student

## Goal
Design a warm, non-judgmental screen where the student indicates writing confidence.

## Prompt

You are a senior product designer and mobile UI specialist.
Design a polished, realistic mobile app screen for WriterHabit AI, an AI writing assistant for Grades 1–12 students.
The app should feel educational, trustworthy, premium, friendly, and implementation-ready.
Use iPhone-style mobile UI patterns unless otherwise stated.

Core product principles:
- The app is a writing coach, not a cheating tool.
- The UI should feel age-appropriate and encouraging.
- Keep accessibility in mind.
- Use clear visual hierarchy, realistic spacing, and polished components.
- Make the design look like a real app, not a wireframe.
- Use a calm educational palette with blue/indigo as primary, light surfaces, teal/green for progress, warm yellow for rewards, and soft red only for errors.
- Typography should be highly readable.
- Ensure the screen feels like part of one cohesive product.
- Localization-ready copy and practical UX patterns.

Brand direction:
- Product name: WriterHabit AI
- Tagline direction: Build better writing skills every day.
- Audience: students, parents, teachers
- Core capabilities: daily assignments, typed writing, handwriting canvas, AI feedback, revision, progress tracking

Required output style:
- Make the screen realistic and polished.
- Show complete UI with navigation, cards, buttons, and useful content.
- Use clean, believable copy.
- Include thoughtful empty/loading/error states only if relevant to this screen.
- Make the screen easy for engineers to implement.


Now design the **Writing Confidence Screen** for the **Student** flow.

Purpose of this screen:
Design a warm, non-judgmental screen where the student indicates writing confidence.

Must include:
4 confidence options with supportive copy, playful but polished illustrations/icons, progress indicator.

Primary CTA:
Primary CTA: Continue.

Screen-specific instructions:
- Make the layout highly believable for a real iPhone app.
- Use content and microcopy that fit the WriterHabit AI product.
- Keep the screen consistent with the rest of the app.
- Include thoughtful states, indicators, and navigation elements that make sense for this screen.
- Show enough detail that an engineer or AI coding agent could implement it.
- If the screen serves younger students, slightly simplify the UI and increase friendliness.
- If it serves older students, parents, or teachers, make it more structured and mature.

Optional agent follow-up:
- Also provide component breakdown.
- Also provide UX notes.
- Also provide implementation notes for React Native / Expo.
