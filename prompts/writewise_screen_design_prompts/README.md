# WriterHabit AI — Screen Design Prompt Pack

This ZIP contains ready-to-use prompts you can paste into an AI design agent to generate or design each major screen for the WriterHabit AI app.

## Included
- 48 individual screen prompt files
- prompts grouped by feature area
- reusable master design context
- one-screen prompt template
- a quick screen inventory

## Suggested usage
1. Start with `MASTER_SYSTEM_PROMPT.md`.
2. Then open the screen prompt you want.
3. Paste both into your AI design or coding agent.
4. Ask the agent to return UI specs, mockups, implementation notes, or code.

## Folder groups
- `01_public_entry/` — Public / entry screens used before onboarding.
- `02_student_onboarding/` — Student onboarding screens that personalize the experience.
- `03_student_home_assignments/` — Student dashboard and assignment flow screens.
- `04_writing_workspace/` — Typed writing, AI coach, revision, and submission screens.
- `05_canvas/` — Canvas and handwriting flow screens.
- `06_feedback_review/` — AI review, rubric, and celebration screens.
- `07_progress/` — Student growth and progress screens.
- `08_parent/` — Parent experience screens.
- `09_teacher/` — Teacher experience screens.
- `10_profile_settings/` — Profile, settings, and accessibility screens.
- `11_subscription/` — Subscription, free trial, and upgrade screens.
- `12_edge_states/` — Empty, offline, and failure states.
